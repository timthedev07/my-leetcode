# Keyboard Shortcuts

| Action | macOS | Windows/Linux |
| --- | --- | --- |
| Open problem search | `⌘K` | `Ctrl+K` |
| Open recent problems | `⌘P` | `Ctrl+P` |
| Focus problem description | `⌘1` | `Ctrl+1` |
| Focus C++ editor | `⌘2` | `Ctrl+2` |
| Focus test/results panel | `⌘3` | `Ctrl+3` |
| Run custom tests | `⌘Enter` | `Ctrl+Enter` |
| Submit to LeetCode | `⌘Shift+Enter` | `Ctrl+Shift+Enter` |
| Format C++ document | `⌥Shift+F` | `Alt+Shift+F` |
| Save draft immediately | `⌘S` | `Ctrl+S` |
| Undo | `⌘Z` | `Ctrl+Z` |
| Redo | `⌘Shift+Z` | `Ctrl+Shift+Z` |
| Close active dialogue | `Esc` | `Esc` |

Search results use arrow keys and `Enter`. Focus returns to the search trigger when the palette closes.

## Editor keys

Monaco retains its normal undo, redo, find, selection, folding and indentation behaviour. The keyboard icon in the editor header toggles **Tab moves focus**. When enabled, `Tab` leaves the editor instead of inserting indentation.

Use `⌘S` to flush a draft immediately. Autosave normally confirms a write within 500 ms.

## Vim

The toolbar toggle persists across restarts. While Vim is active, `Esc` returns
to Normal mode and the compact status bar shows the current editing mode.
Application shortcuts are handled before Vim command processing.
